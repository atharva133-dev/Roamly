<div align="center"> <h1>GlobeTrotter</h1> <p>Your intelligent companion for seamless, AI-driven travel itinerary generation and discovery.</p> </div>

<hr>

<h2>Core Functionality</h2> <ul> <li><strong>AI Itinerary Generation:</strong> Utilizes advanced LLMs to generate detailed trip plans, including daily activities, estimated costs, and travel summaries based on user preferences.</li> <li><strong>Interactive Travel Visualization:</strong> Features a dual-view interface with an integrated <strong>Map View</strong> for geographical orientation and a <strong>Calendar View</strong> for chronological scheduling.</li> <li><strong>Background Job Processing:</strong> Implements a robust <strong>Redis-backed BullMQ</strong> system to handle intensive AI generation tasks asynchronously, ensuring a responsive user experience even during complex plan creation.</li> <li><strong>Community Discovery:</strong> Includes a <strong>Community Page</strong> where users can browse, search, and draw inspiration from public trip listings created by other travelers.</li> <li><strong>Administrative Dashboard:</strong> Provides comprehensive analytics and management tools, including user trends, popular city statistics, and activity distribution charts.</li> </ul>

<h2>Technical Architecture</h2> <ul> <li><strong>Frontend:</strong> Developed with <strong>Next.js</strong> (App Router) and <strong>TypeScript</strong> for a high-performance, type-safe web experience.</li> <li><strong>Styling:</strong> Crafted using <strong>Tailwind CSS</strong> and <strong>Shadcn UI</strong>, featuring interactive elements like highlighters and animated globes.</li> <li><strong>Backend & Database:</strong> Powered by <strong>Prisma ORM</strong> with a PostgreSQL database, managing complex relational data for users, trips, and reviews.</li> <li><strong>Authentication:</strong> Integrated with <strong>Clerk</strong> for secure, modern user management and social login capabilities.</li> <li><strong>Task Queue:</strong> Employs <strong>Redis</strong> and <strong>BullMQ</strong> to manage worker-based processing for LLM-heavy tasks.</li> </ul>

<h2>Installation Instructions</h2> <ol> <li>Clone the repository: <code>git clone https://github.com/Rakshat28/GlobeTrotter.git</code>.</li> <li>Install the required dependencies: <code>npm install</code>.</li> <li>Configure environment variables by copying <code>.env.example</code> to <code>.env</code> and providing your Clerk, Prisma, and Redis credentials.</li> <li>Sync the database schema: <code>npx prisma db push</code>.</li> <li>Initialize the Redis environment: <code>npm run setup-redis</code>.</li> <li>Start the development server: <code>npm run dev</code>.</li> <li>In a separate terminal, start the background workers: <code>npm run start-workers</code>.</li> </ol>

<h2>Usage Guide</h2> <ol> <li><strong>Plan a Trip:</strong> Navigate to the <strong>Travel Planner</strong>, enter your destination, and let the AI generate a custom summary and itinerary.</li> <li><strong>Review Your Schedule:</strong> Switch between <strong>Map</strong> and <strong>Calendar</strong> views to see exactly where and when your activities take place.</li> <li><strong>Explore Community:</strong> Visit the <strong>Community</strong> section to see trending destinations and save plans shared by others.</li> <li><strong>Manage Trips:</strong> Access your personal <strong>Trip Listing</strong> to view, edit, or delete your previous itineraries.</li> <li><strong>Admin Access:</strong> Authorized administrators can view <strong>Real-time Stats</strong> and user management metrics through the admin dashboard.</li> </ol>
